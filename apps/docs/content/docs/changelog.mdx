## Where this comes from

Release notes are written with [Changesets](https://github.com/changesets/changesets). Each change to the package comes with a short note, and when a version is cut those notes are collected into `CHANGELOG.md` in the package. This page is built from that file, and from the notes that haven't been collected yet.
