title: Label
description: The text that names a form control. A click on it goes to the control, and a double click doesn't select its words.
---

Use a label for the visible name of an input, a select or any other control. For a label that also carries a hint and an error message, use [Field](/docs/components/field), which renders this component for you.

```sh
pnpm add @nuvui/react
```

```tsx
import { Label } from "@nuvui/react";
```

The styles come from `@nuvui/react/styles.css`, which you load once for the whole app. [Getting started](/docs) covers that, and how to load only this component's CSS.

## Accessibility

A label has no keyboard behavior of its own. Focus goes to the control it names.

### What the component handles

- It renders a native `<label>`, so the browser ties it to the control: a screen reader reads the label's text as the control's name, and a click or a tap on the label focuses or toggles the control.
- A double click on a label selects its text in most browsers, which gets in the way when someone clicks a checkbox's label twice. This one doesn't. That part is Radix.
- A click on a button, an input or a select inside the label is left alone.

### What you need to handle

- Point it at the control. Set `htmlFor` to the control's `id`, or put the control inside the label.
- Keep it visible. A placeholder isn't a label: it disappears as soon as someone types.
- A label can't tell whether its control is disabled. Set the `data-disabled` attribute on it to fade it. Field does this for you.

## Server components

Label is a client component. It carries `"use client"`, and the build checks that the directive is still there in the published files. You can render it from a server component, as the examples on this page do.

## Do and don't

**Do**

- Give every control a label that people can see.
- Keep it short, and put any explanation in a description under the control.

**Don't**

- Don't use a placeholder in place of a label.
- Don't put a link or a button inside a label. A click on it is ambiguous.
